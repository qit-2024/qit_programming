Inverse Matrix
This feature calculates:
- matrix's determinant,
- cofactor's matrix,
- adjugate matrix
- inverse matrix
for a given NxN (N > 0) square matrix.

The determinants are calculated using Laplace expansion.

Input example:
For 3x3 matrix like this:
[1, 2, 3]
[4, 5, 6]
[7, 8, 9]
Input looks exactly like this:
[1, 2, 3, 4, 5, 6, 7, 8, 9]
