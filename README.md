QIT Programming:<br>
This application has two features:<br>

* LeetCode<br>
This is a solution for LeetCode problem ["2. Add Two Numbers"](https://leetcode.com/problems/add-two-numbers/).<br>

* Inverse Matrix<br>
This feature calculates:<br>
\- matrix's determinant,<br>
\- cofactor's matrix,<br>
\- adjugate matrix<br>
\- inverse matrix<br>
for a given NxN (N > 0) square matrix.<br><br>
The determinants are calculated using Laplace expansion.<br><br>
