This application calculates:  
\- matrix's determinant,  
\- cofactor's matrix,  
\- adjugate matrix  
\- inverse matrix  
for a given NxN (N > 0) square matrix.<br/>

The determinants are calculated using Laplace expansion.<br/>

Requirements:  
./Syllabus/: pip install -r requirements.txt<br/>

Start:  
./Syllabus/: python manage.py runserver<br/>

WEB server access:  
127.0.0.1:8000/<br/>
